# v0.2.0 - Versione 1: Tiny9990 command-completion fix

Published 2026-11-24. Experimental firmware for WonderTANG 2.0b / 2.02b
with Tang Nano 20K. This is the exact image tested locally as "Versione 1".

## Change

P#6.CE now reads `CE_save | STATUS.CE_intr` instead of
`CE_save | STATUS.CE`. P#5.CE remains the command-executing/busy flag.
Yamaha distinguishes command completion and command execution in the V9990
Application Manual, printed page 76:
https://map.grauw.nl/resources/video/yamaha_v9990.pdf

The UMA controller, memory map, clocks, resolution, supported color modes and
OPL4 implementation are unchanged from the previous integration. No HDMI audio
and no Nextor are added. The new-arbitration "Versione 2" is not included.

## Verification and observations

- Gowin 1.9.12, placement 2 / routing 0; zero analyzed setup/hold violations.
- Minimum setup slack: 0.009 ns; logic 19524/20736, CLS 10200/10368,
  BSRAM 42/46. Constraints remain inherited and are not a full timing audit.
- Completion-flag truth table, FIFO pointer/rotation and envelope arithmetic
  checks pass. No full event-driven RTL simulation has been performed.
- Owner reports good simultaneous V9990 graphics and OPL4 audio with Monkey
  Island 1 and 2 conversions, improving on colors/glitches in the earlier
  firmware. Exact game builds, duration and full playthroughs were not recorded.
- BASIC validation and broader game compatibility remain incomplete.

## Gowin programming / programmazione

1. Spegnere il MSX ed estrarre la cartuccia, poi collegare USB-C al PC.
2. Rilevare GW2AR-18 in Gowin Programmer. Impostare External Flash Mode,
   Generic Flash, `exFlash Erase,Program thru GAO-Bridge`.
3. Selezionare `wonder_opl4_v9990_v0.2.0.fs` e Start Address `0x000000`.
   Abilitare solo questa riga, Save e Program/Configure; verificare il log.
4. YRW801 non e inclusa: se gia corretta a `0x200000` e fuori dall'area
   cancellata dal .fs, non riscriverla. Altrimenti usare la propria ROM da
   2.097.152 byte, operazione C Bin, a `0x200000` (`0x0200000` nella maschera
   con sette cifre). Il log deve mostrare l'indirizzo numerico corretto.
5. Scollegare USB prima di reinserire la WonderTANG nel MSX spento.
   Avviare da Pico+ o altra interfaccia. Audio da J3/SOUNDIN, non da HDMI.

Non eseguire una cancellazione globale dopo aver scritto le ROM.
